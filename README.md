# Stronghold Mobile

Мобильная стратегия в духе Stronghold (Firefly Studios): замок, экономические цепочки,
популярность народа, осады.

**Текущий этап: 4 — общество.** Карта, камера, игровой цикл, рендер со спрайтами,
нагрузочный тест.

Масштаб: тайл 32 px, кадр юнита 64 px.

## Ассеты

- `assets/sprites/units64.png` — юниты, генерируются `tools/gen_sprites_v4.py`
- `assets/craftpix/` — деревья, камни, кусты, руины, звери, база персонажа (CraftPix)

Паки CraftPix взяты из бесплатных наборов. Перед публикацией игры нужно свериться
с их лицензией: бесплатные паки обычно можно использовать в коммерческих проектах,
но нельзя перепродавать и распространять сами файлы.

Архитектура и план этапов: [ARCHITECTURE.md](ARCHITECTURE.md)

## Запуск локально

Модули требуют http, файл через `file://` не откроется:

```
python3 -m http.server 8080
```

Открыть `http://localhost:8080`
